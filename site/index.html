Bring your own games. PSP-Emulator reads discs you already have — it ships no game data and no firmware.

Built to feel like the hardware

The actual cross

Categories run along a horizontal line, the selected category's items down a vertical one, and the selection sits where they meet — both sliding so it stays pinned. Laid out in the PSP's own 480×272 space and scaled to your window, so the proportions are the console's, not an approximation.

A wave that never loops

Built from summed sines at incommensurable frequencies and composited additively, so ribbons bloom where they cross and the motion never visibly repeats.

Twelve months of colour

A real PSP recolours its wallpaper by the system month. So does this — all twelve, from February's pink to October's orange.

Real metadata, no scraping

Titles, disc IDs and 144×80 icons come from each game's own PARAM.SFO and ICON0.PNG — parsed out of ISO9660, decompressed out of CSO, or read from a PBP's section table. No online database, no guessing from filenames.

PS5, PS4 and Xbox pads

Connect a DualSense, DualShock 4 or Xbox controller by USB or Bluetooth and it works with no mapping step. The pad is identified by name, the on-screen hints switch to its own buttons — ✕/○ or A/B — and it rumbles on connect and launch. If PPSSPP already has a mapping configured, the XMB reads it and agrees with the game rather than contradicting it. Pads reporting a non-standard mapping or a hat-axis D-pad are handled too, which is where most implementations quietly break.

Saves that follow you

Optional cloud sync keeps one save state per slot per disc across your machines, skipping any upload whose checksum has not changed.

How it fits together

1

The shell

A TypeScript XMB rendered in a Tauri webview. Its navigation is a pure state machine, so the console's quirks — no wrapping at column ends, per-category cursor memory, horizontal input trapped in submenus — are pinned by tests.

2

The host

Rust reads your ROM folders, parsing PARAM.SFO, PBP, ISO9660 and CSO directly, and hands back titles and icons. It locates PPSSPP and spawns it without a shell, so unusual paths stay safe.

3

The emulator

PPSSPP does the emulating — it is the mature, well-tested project for that, and reimplementing an Allegrex VFPU would serve nobody. This is the shell around it.

4

The backend

Base44 serves this page, the release manifest the app checks for updates, and the save-state sync. Game data never leaves your machine.

Download

Checking for the latest build…

A game is already included

Every installer ships with homebrew we wrote ourselves, so there is nothing to find before you can play. Open Game and pick Install Bundled Games — the shell copies it into your library and rescans, and you are in.

Want the file on its own, or already have your own dumps? Grab it from the release assets, or point Settings → Add ROM Folder at any folder of your own.

Getting started, in three steps

  1. Install PPSSPP. Grab it from ppsspp.org. PSP-Emulator does the front-end; PPSSPP does the emulating. Nothing else to configure — the app finds it on your PATH or in the default install location, and Settings → Emulator lets you point it anywhere.
  2. Install PSP-Emulator from the download above and open it. You will land on the XMB with an empty Game list, which is expected: the app ships no game data.
  3. Point it at some games. Choose Settings → Add ROM Folder and pick any folder of .iso, .cso or .pbp files. Titles, disc IDs and cover art are read straight out of each file, so the list fills itself in.

No games yet? Two legitimate routes: rip a UMD you own with a PSP and a compatible drive — PPSSPP's dumping guide covers the whole process — or load PSP homebrew, which its authors release freely and which runs here exactly like a retail disc.

A note on the first launch. These builds are not code-signed, so macOS will refuse to open the app until you right-click it and choose Open, and Windows SmartScreen will show a warning where you pick More info → Run anyway. Nothing is wrong with the download — signing certificates cost money this project does not have. Every release ships a SHA256SUMS.txt if you would rather verify the file yourself.
